# CLI 故障速查

调用异常时对照当前 commands、原始返回和现有产物；这里只解释错误并选择 CLI 支持的下一步，不代提 Issue、上报数据或修改 CLI。

## 保留最小现场

记录实际命令、退出码、error.code/message/hint、相关 JSON 与 sid/action/request/产物路径。凭据、Cookie、token 和业务敏感值脱敏；正常断言失败不另造一套上报材料。

## 按事实处理

| 事实 | 下一步 |
|---|---|
| 参数拼错、旧索引或错误 target | 查对应 commands 与最新 state，修正调用 |
| Skill 示例与当前定义不一致 | 以当前 CLI 为准，指出差异与可用替代，不误报 CLI bug |
| 缺所需命令或参数 | 说明能力缺口与未执行项，BLOCKED |
| 合法调用的返回/产物与合同矛盾 | 给出具体差异，补最小只读诊断；证据不足不确认根因 |
| 断言失败或业务拒绝 | 保留预期/实际和原生报告，不把业务失败当工具缺陷 |
| 登录、权限、网络或浏览器前置失败 | 给原始错误与 doctor/state 等适用诊断，不自动换身份 |
| 超时、异常码但动作终态未知 | 读原 session/action 的 state/trace，保留不确定性；错误码不是根因 |

诊断仍遵守 [SKILL.md](../SKILL.md) 的身份、授权与重试约定：**超时不证明点击/提交未执行**，不能为补证据重做已成功或结果未知的页面写。收尾与结果判读见 [acceptance.md](acceptance.md)。
